# RAG Vercel Example

This repository contains an AI bootcamp capstone project that demonstrates a Retrieval-Augmented Generation (RAG) system deployed on Vercel.

## Project Details

- **Project Type**: AI Bootcamp Capstone Project
- **Date**: August 2025
- **Author**: Santosh Edulapalle

## Description

This project implements a RAG (Retrieval-Augmented Generation) system that combines document retrieval with language model generation to provide more accurate and contextual responses. The application is designed to be deployed on Vercel for easy access and scalability.

## Features

- Document retrieval and processing
- AI-powered question answering
- Web-based chat interface
- Vercel deployment ready

## Getting Started

1. Clone the repository
2. Create a virtual environment: `python3 -m venv .venv`
3. Activate the virtual environment: `source .venv/bin/activate`
4. Install uv in the virtual environment: `pip install uv`
5. Install project dependencies: `uv pip install fastapi uvicorn openai python-dotenv mmh3 requests jinja2`
6. Run the application locally

## Deployment

This project is configured for deployment on Vercel with the included `vercel.json` configuration file.
